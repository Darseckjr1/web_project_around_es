# Around The U.S.

## Descripcion del proyecto

Around The U.S. es una página para compartir paisajes alrededor de U.S

## Funcionalidad

El sitio web Around The U.S. nos da la posibilidad de cambiar sus elementos tales como el nombre y profesión de nuestro perfil, además de permitirnos agregar o eliminar tarjetas.

También se agrego la función de indicar "Me gusta" a una imagen haciendo que el icono cambie de color.

De igual manera si presionamos en el icono "Eliminar tarjeta" está se eliminará de nuestro perfil.

Finalmente la función para ampliar las imágenes de la tarjetas; al hacer click sobre las tarjetas estás abriran un pop up con la imagen ampliada y su título, también aparecerá un botón para cerrar este popup.
